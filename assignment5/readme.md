Component Plan

Webpage the component will be applied to:
Homepage

Type of component:
Featured three card section showing each Outlast game (Outlast, Whistleblower, Outlast 2).

Why it's needed:
The cards help users quickly compare the three games visually and understand the differences between them. 
They also break up the page visually and make the homepage more engaging.

Features:
• Section heading
• Three cards
• Each card includes an image, game title, year, and short description
• Cards arranged side by side on desktop and stacked on mobile

What you'll use to build it:
Flexbox for the card layout (desktop row layout, mobile column layout).
